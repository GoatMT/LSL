# Lantern Rush audio credits

Lantern Rush has no music. The game plays these locally bundled effects for match ambience, player actions, match events and interface feedback. Files stay with the static game, so browser audio does not rely on an external server.

| Footsteps, impacts, ball contacts, posts and collisions | Kenney, [Impact Sounds](https://kenney.nl/assets/impact-sounds) | CC0 1.0. The original pack license is included as `impact-sounds-License.txt`. |
| Referee whistle variants | SFXMint, [Instrument Whistle 01](https://sfxmint.com/sounds/instrument-whistle-01), [02](https://sfxmint.com/sounds/instrument-whistle-02), [03](https://sfxmint.com/sounds/instrument-whistle-03) | CC0 1.0 |
